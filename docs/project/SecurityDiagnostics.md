# Security Diagnostics

Security diagnostics are deterministic descriptions of declaration or observation
inconsistencies. They do not enforce a policy.

The audit detects missing contract references, an empty registry, unknown
decisions, unclassified violations or incidents, incompatible policies,
runtime activation without explicit adoption, and duplicate observation IDs.

Diagnostics are sorted by code, subject, and message. An empty diagnostic set is
valid. Consumers decide independently how diagnostics affect their operations.
