# Security Zones

| Zone | Responsibility |
| --- | --- |
| Core | Fundamental EPIP types and contracts |
| Framework | Public orchestration surface |
| Kernel | Component and plugin orchestration |
| Engine | Financial domain engines |
| EventBus | Event publication and subscription boundary |
| Plugin | Extensible third-party behavior |
| Provider | Data acquisition integrations |
| Adapter | External execution integration |
| External | Systems outside EPIP ownership |
| System | Operating-system services |
| User | Caller-controlled input and configuration |
| Network | Network transport and remote payloads |
| Filesystem | Persistent local files and paths |

Zones are architectural classifications, not runtime sandboxes.
