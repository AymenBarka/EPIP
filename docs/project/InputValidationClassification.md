# Input Validation Classification

| Category | Declared concern |
| --- | --- |
| Type validation | Expected Python or domain type |
| Nullability | Whether absence is permitted |
| Range validation | Numeric or ordered bounds |
| Enum validation | Membership in an allowed set |
| Format validation | Textual or protocol format |
| Structure validation | Shape and required members |
| Identity validation | Stable identity and references |
| Resource validation | Resource existence or availability |
| Security validation | Security-sensitive input assumptions |
| Configuration validation | Configuration shape and constraints |

Severity ranges from informational declarations to critical boundary
requirements. No severity activates runtime enforcement.
