# Security Stress Campaign

The H007 campaign executes 100,000 resolutions for security, boundary, validation,
runtime-policy, and secure-failure contracts. A separate 1,000-cycle end-to-end
campaign builds snapshots, diagnostics, and canonical reports.

The workload is read-only. It validates registry completeness, decision stability,
failure visibility, and recovery after rejected declarations. No runtime state or
financial calculation is modified.
