# Release v1.3.0

## Highlights and modules

Added EPIP-013 Risk Engine as the sole sizing and risk-planning authority. The release introduced
`PositionPlan`, fixed/amount/Kelly/fractional-Kelly/ATR/volatility sizing, exposure and drawdown
limits, stops, targets, leverage, margin, graph, history, events, and serialization.

## Architecture changes

Risk consumes only the official Decision output. `PositionPlan` became the only position object for
Execution, Portfolio, and AI consumers, eliminating duplicated sizing calculations.

## Quality and tests

Black, Ruff, strict MyPy, and Pytest passed. The reference validation ran 186 tests with 96%
aggregate coverage. Tests covered sizing, Kelly, ATR, volatility, exposure, drawdown, leverage,
margin, stops, targets, Decision integration, history, graph, and serialization.

## Benchmarks

Reference local runs measured 100k calculations in approximately 0.142 s and 1M in approximately
1.413 s: about 703k–708k calculations/s with roughly 1.41–1.42 µs average latency. Memory figures
were estimates rather than RSS measurements.
