# Release v1.0.0-pre

## Highlights

The pre-1.0 milestone completed EPIP's analytical foundation from Core Domain through Market
Context, creating the shared architecture used by later action engines.

## Modules added

Core Domain, EventBus and Kernel, Feature Store, Market Data, Replay Engine, Swing Engine, Market
Structure Engine, Liquidity Engine, Fibonacci Engine, and Market Context Engine.

## Architecture changes

Established bounded packages, provider protocols, event-driven integration, immutable snapshots,
append-only histories, lineage graphs, versioned context, deterministic serialization, and
thread-safe engine orchestration.

## Quality and tests

Black, Ruff, MyPy, and Pytest passed. Coverage across the milestone's recorded modules was 95–96%.
Tests covered providers, cache, replay, swing detection, structure state, liquidity, Fibonacci,
Context aggregation, serialization, graphs, histories, and events.

## Benchmarks

Per-engine benchmarks were introduced for EventBus, Kernel, Feature Store, Market Data, Replay,
Swing, Structure, Liquidity, Fibonacci, and Context. Results are environment-specific; the tag does
not contain a consolidated hardware baseline.
