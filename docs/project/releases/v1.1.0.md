# Release v1.1.0

## Highlights and modules

Added EPIP-011 Elliott Wave Engine: detection, validation, wave counts, alternate counts, degrees,
rules, projections, targets, confidence/probability/quality scoring, graph, history, events, and
Market Context integration.

## Architecture changes

Wave interpretations became immutable, versioned hypotheses with explicit alternatives and lineage
rather than hidden mutable analyzer state. Market Context remained the official aggregate input.

## Quality and tests

Black, Ruff, MyPy, and Pytest passed with 96% coverage. Tests covered engine behavior, rules,
patterns, alternate counts, projections, Context validation, events, graph/history, and
serialization.

## Benchmarks

An Elliott benchmark was added for repeatable local performance measurement. No portable
throughput claim is attached because timing depends on interpreter, hardware, and workload.
