# Release v1.5.4

## Purpose

This maintenance release corrects annotated-tag validation in the GitHub Actions release workflow.

## Correction

The workflow now explicitly fetches the pushed tag before verifying its Git object type. This
removes its dependency on whether `actions/checkout` creates a local tag reference on the runner.

## Scope

This release changes repository automation and release metadata only. It does not modify framework
implementation, public APIs, tests, benchmarks, or financial behaviour.

## Validation

The release workflow verifies semantic versioning, annotated tags, release notes, roadmap,
changelog, package version, quality gates, and strict documentation builds.
