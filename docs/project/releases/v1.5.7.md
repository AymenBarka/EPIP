# Release v1.5.7

## Purpose

This release delivers Hardening-003 Financial Correctness.

## Scope

Hardening-003 corrects periodic PnL semantics, formalizes average-cost accounting, validates
commission and weighted-fill calculations, and enforces exposure, margin, PnL, equity, drawdown,
and allocation identities.

Deferred capabilities such as multi-currency conversion, settlement, instrument specifications,
trading calendars, mark-to-market providers, and statistical correlation remain out of scope.

## Validation status

The framework quality, documentation, and CodeQL checks passed before merge. The published tag's
release-validation workflow failed because its release notes, roadmap reference, changelog entry,
and package version were not present at the tagged commit. The tag remains unchanged for audit
integrity; v1.5.8 provides the metadata correction.
