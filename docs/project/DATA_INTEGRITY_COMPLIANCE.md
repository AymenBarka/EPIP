# Hardening-002 compliance matrix

## Contract

Every pipeline boundary accepts only frozen dataclasses. Objects exposing
`validate_integrity()` receive their domain-specific validation followed by the
universal structural validation. EventBus requires the explicit protocol.

The automated inventory currently covers **278 immutable business dataclasses**:
64 have a class-specific contract and 214 use the universal structural contract.
Its approved SHA-256 fingerprint is
`fcf14ec080715cfda8a13336d52909cd6a8f008d72d3b4d95cdc5c798527f9bb`.
Any added, removed, renamed, or reclassified frozen dataclass changes that
fingerprint and fails CI until an architect reviews its invariants.

The inventory and its full Markdown report are generated by
`epip.core.integrity_compliance`. The compliance tests verify that every entry
appears in the report; no hand-maintained class list is used.

The parameterized acceptance matrix also proves that the 13 official public
engine boundaries reject invalid immutable input with `DataIntegrityError`
subclasses and share the same guarded output contract.

## Immutability

Metadata and arbitrary feature payloads are recursively copied and frozen.
Serialization creates detached mutable representations without exposing the
stored immutable values.

## Exceptions

Malformed serialized data is translated to `SerializationIntegrityError`.
Missing data, invalid numbers, versions, relationships and event contracts use
their corresponding `DataIntegrityError` subclass.
